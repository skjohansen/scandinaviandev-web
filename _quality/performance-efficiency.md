## What performance efficiency means

Performance efficiency shows up in three characteristics:

- **Time behaviour** — response and processing times meet requirements
- **Resource utilisation** — the amounts and types of resources used are proportionate
- **Capacity** — the maximum limits of the product meet current and future requirements

## Fast software is disciplined software

The practices that keep software fast — lean dependencies, automated
tests, tight feedback loops — are the same ones that keep vulnerabilities
out. Every unused dependency is attack surface you maintain but never
benefit from.

## Performance without security rework

Security checks run in the pipeline, without slowing your releases. When
your team spots risky patterns before code is written, there is no security
rework late in the release cycle — and releases stay fast.
