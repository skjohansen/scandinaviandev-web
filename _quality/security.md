## What security means

In practice, security comes down to five characteristics:

- **Confidentiality** — data is only accessible to those with the right to see it
- **Integrity** — data and system behaviour cannot be tampered with
- **Non-repudiation** — events and actions can be proven to have taken place
- **Accountability** — actions can be traced back to their origin
- **Authenticity** — the identity of a subject or resource can be verified

## The goal of security is resilience

Security is not about locks and fear. The goal is resilience: software that
keeps working, even under attack. Security built in from day one instead of
bolted on before launch — threat modelling, secure code and security
automation in your pipeline, practised by the engineers you already have.
